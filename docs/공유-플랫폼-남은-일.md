# 공유 플랫폼 — 남은 일

악보 게시·모아보기를 열면서 **알면서 미뤄 둔 것들**입니다. 잊고 다시 발견하지 않으려고 적어 둡니다.
구조와 규칙은 `CLAUDE.md`의 '악보 게시'·'모아보기' 절에, 서버는 `server/schema.sql`에 있습니다.

마지막 갱신: 2026-08-11 (모아보기를 연 날)

---

## 1. 지은이·이용 조건을 나중에 못 고친다

`update_score`가 고치는 것은 **문서·공개 여부·미리보기**뿐입니다. `author`와 `license`는 게시할 때
정한 값이 굳습니다. 그래서 이름이나 이용 조건을 바꾸려면 **내렸다 다시 올려야 하고 주소가 바뀝니다.**
실제로 이 때문에 두 번 다시 올렸습니다(지은이 이름 정정, CC BY → 저작권 유보).

고치려면 `server/schema.sql`의 `update_score`에 인자 둘을 더하고 SQL을 다시 실행하면 됩니다.

```sql
-- update_score(p_id, p_token, p_doc, p_public, p_thumb, p_author, p_license)
--   author  = coalesce(nullif(p_author,''), author)
--   license = case when p_license is null then license else p_license end
-- + 이용 조건 값 검사(publish_score와 같은 목록)
```

인자가 바뀌므로 `drop function if exists public.update_score(text, text, jsonb, boolean, text);`가
먼저 필요하고, `js/cloud.js`의 갱신 호출과 게시 창(지금은 갱신할 때 지은이·조건 칸이 무시됨)도 함께.

## 2. 반복 위반자를 막을 수단이 없다

약관 제6조 제5항에 근거는 적어 두었지만, **계정이 없어 실행할 수단이 없습니다.**
지은이 이름도 자유 입력이라 사칭을 막지 못합니다. 둘 다 **로그인을 붙여야 풀리는 하나의 문제**입니다.
`scores.visibility`에 `private`을 미리 받아 두었고 `profiles` 같은 표를 붙일 자리는 비어 있습니다.

## 3. 중단 내역은 손으로 적는다

`notices.html`은 정적 표입니다. 신고로 악보를 내리면 `<tr>`을 손으로 한 줄 더해야 합니다
(적는 법은 그 파일 `<tbody>` 주석). 서버에서 가져오지 않는 것은 의도한 선택입니다 —
신고가 들어와야 쓰이는 페이지라 자동화할 양이 아니고, 사유는 사람이 적어야 하는 말이라서.

## 4. 도움말 문구가 새 기능을 모른다

`docs/도움말-문구.md`를 아직 다시 뽑지 못했습니다(작업 환경에 node가 없었음). 그래서 새로 생긴
**[악보 게시]·[모아보기] 버튼의 툴팁**이 그 문서에 빠져 있습니다.

```bash
node tools/gen-help-doc.mjs      # 문서가 손대진 상태면 멈춘다 → 버릴 땐 --force
```

이 문서는 손으로 고치는 것을 막지 않으므로, 손댄 내용이 있으면 먼저 살펴보고 결정해야 합니다.

## 5. 아직 안 올린 예시 악보 둘

`samples/우락 羽樂.jgb.json`, `samples/웃도드리.jgb.json` — **출판본을 옮긴 것**이라 하셨으므로,
민요 셋과 같이 **부제에 출처를 적고 이용 조건을 '저작권 유보'로** 올리면 됩니다.
어느 책인지 정해지면 부제 끝에 `// 출처: …`를 붙이는 방식(민요 셋과 같음).

## 6. 씨앗 악보의 수정 열쇠

`server/tokens.local.json`(gitignore)에 있습니다. **이 파일을 잃으면 그 게시물은 API로 못 고치고
못 내립니다** — 그때는 Supabase SQL Editor에서 직접 지워야 합니다. 백업해 두는 편이 좋습니다.

## 7. Supabase 무료 플랜은 일주일 무접속이면 멈춘다

프로젝트가 일시정지되면 게시·열기가 모두 실패합니다. 방문이 꾸준하면 안 걸리지만, 조용한 시기가
길어지면 유료 전환이나 주기적 접속이 필요합니다.

## 8. 미리보기 그림의 여백

카드 그림은 악보 첫 장을 통째로 담습니다. 짧은 곡이 A4에 있으면 아래가 비는데, **종이 크기를
고를 수 있게 되면서 대부분 풀렸습니다**(짧은 곡은 정사각·A5). 그래도 허전하면 `makeThumb`에서
잉크 경계로 잘라 담는 길이 남아 있습니다.

## 9. 경로 주소(/s/…)와 공유 카드

지금 주소는 해시(`#v=…`)입니다. GitHub Pages가 경로 리라이트를 못 해서인데, 카톡·트위터
**공유 카드(OG 태그)** 가 필요해지면 경로 주소로 옮겨야 하고 그때 호스팅(Cloudflare Pages 등)도
함께 옮기게 됩니다.
