# 우물사이(정간보 편집기) — 기능·설정 총정리

정간보(井間譜) 생성기 웹앱이 제공하는 거의 모든 기능과 설정을 정리한 사용자용 문서입니다.

## 0. 개요

- **구조**: `index.html`(마크업, 루트) + `css/styles.css`(스타일) + `js/` 아래의 로직·데이터.
  - `js/app.js` 전체 로직 · `js/symbols-registry.js` **기호 사전**(시김새·곁줄 기호·장구 구음의 이름과 놓일 자리) · `js/tour-text.js` 둘러보기 문구 · `js/analytics.js` 익명 사용 통계 래퍼(19장 참고).
  - 데이터 파일 3개: `js/notes-data.js`(율명·기호 이미지) · `js/symbols-data.js`(시김새·특수기호 SVG) · `js/janggu-data.js`(장구 구음 7종). 이미지가 전부 base64로 내장되어 있어 외부 리소스 없이 동작합니다.
- **서버/DB 없음**: 정적 파일만으로 동작하는 클라이언트 사이드 앱입니다.
- **자동 저장**: 브라우저 `localStorage`에 실시간 자동 저장되어 새로고침해도 유지됩니다(11장 참고).
- **읽는 순서**: 전통 방식 그대로 **오른쪽 → 왼쪽**으로 각(세로줄)이 진행됩니다.

### 화면 구성

| 영역 | 내용 |
|---|---|
| 상단바 | 왼쪽에 **문패**(로고 + 두 줄 이름 '우물사이 / 정간보 편집기' + **BETA 배지**) · **재생 컨트롤**(▶/■/⚙) · 오른쪽에 **보기**(총보/파트보 — 악기가 둘 이상일 때만)·**보기 배율**(−/숫자▾/＋)·**오선보 보기**·**색상**(색상 테마 3종·다크 전환 메뉴)·**＋ 새 문서**·**인쇄**·**⋯ 파일**(PNG·파일로 저장·오선보 내보내기·링크 복사·악보 게시·불러오기·전체 초기화)·**모아보기**·**도움말**·**설정** |

| 가운데 악보 영역 | SVG 악보 미리보기 (줌 바·재생 바는 상단바로 옮겨져 항상 같은 자리에 고정). **오선보 보기**를 켜면 그 아래에 오선보 칸이 함께 열립니다(14장) |
| 기능바(리본) | 마우스 모드 · 입력(도구창 5개) · 각 삽입/삭제 · 정간 편집 · 율명 크기 · 곁줄 크기. **기본으로 왼쪽 세로 사이드에 도킹**(위치 전환 버튼으로 악보 위 가로 배치와 오감, 도크 폭은 손잡이를 끌어 조절 — 16장 참고). 좁으면 줄바꿈으로 접혀 항상 전부 보임 |
| 뜬 도구창 | **율명/시김새**(한 창) · **곁줄** · **장단** · **빠르기/각/장** · **텍스트** · **정간 서식** 창이 한 번에 하나만 열림. 기본(왼쪽 도킹)에선 기능바 아래에 도킹되어 사이드바처럼 정리되고, 가로 배치에선 악보 위에 떠서 그립(⠿)으로 끌어 이동. 오른쪽 위 ✕로 닫기 |

- **BETA 배지**: 문패 옆 배지를 누르면 저장 안내 팝오버가 열립니다 — 자동 저장은 브라우저·기기 환경에 따라 사라질 수 있으니 수시로 `.json`으로 내려받으라는 안내와 **지금 파일로 저장** 버튼.

## 1. 새 문서 만들기 (마법사)

상단바 오른쪽의 **＋ 새 문서** 버튼을 누르거나, **저장된 작업이 전혀 없는 첫 방문**이면 자동으로 마법사가 뜹니다.

| 항목 | 설명 |
|---|---|
| 한 각의 정간 수 | 한 각(세로줄)에 들어갈 정간(칸) 수. 기본 12 |
| 대강 분절 (선택) | 굵은 선으로 나눌 정간 묶음(예: `3 3 3 3`). 비우면 박 수에 맞는 대표 패턴 자동 입력 |
| 총 각 수 | **비워두면 기본 8각**(회색 안내 표시). 만든 뒤에는 이 값이 그대로 유지되고 자동으로 늘어나지 않음. **선율이 들어갈 각만** 세며, 장단을 넣으면 장단 줄이 맨 앞에 한 각 자리를 따로 차지합니다 |
| 곡 제목 (선택) | 비우면 제목 없이 생성. 옆에서 **세로 칸 / 가로 위** 표기 방향 선택 |
| 부제 (선택) | 제목 아래 작은 글씨. 제목·부제 모두 `//`를 넣으면 그 자리에서 줄바꿈 |
| 장단 입력 사용 | 켜면 장단 줄이 곡 맨 앞에 추가됨 |

새 문서를 만들기 전에 **지금 작업을 임시저장할지** 물어봅니다. 전체 초기화(상단바 ⋯ **파일** 메뉴)는 이와 달리 리로드 없이 **내용만**(선율·곁줄·장단·텍스트·정간 서식) 지우고 레이아웃 설정은 유지하며, ⌘/Ctrl+Z로 복구할 수 있습니다.

**저장된 작업이 전혀 없는 첫 화면은 8각 한 줄**입니다. 아직 아무것도 정하지 않은 사람에게 빈 격자가 두 줄이나 깔리면 부담스러워, 페이지를 꽉 채우던 예전(20각·두 줄) 대신 한 줄만 그립니다. 한 줄에 놓을 각 수 기본이 10이라 장단을 켜도(한 각 자리 차지) 한 줄에 들어갑니다.

## 2. 입력 방법 (직접 입력)

악보를 직접 클릭해 그 자리에서 쓰는 방식 하나로 통일되어 있고, 선율·곁줄·장단 모두 같은 방식입니다.
(텍스트 에디터 모드의 마크업·배선은 남아 있지만 **상단바에서 숨겨져** 지금은 쓰지 않습니다.)

- **악보의 정간을 클릭하면 그 자리에 입력 카드**가 열려 보이는 그대로 입력합니다. 문법을 몰라도 됩니다.
  - `Enter`/`Tab` 다음 정간, 방향키로 인접 정간 이동, `Esc` 닫기.
  - **처음 정간을 클릭하는 순간 율명 팔레트가 한 번 자동으로 열립니다** — 닫으면(✕) 그 뒤로는 다시 저절로 열리지 않고, 시김새 등 다른 창을 열어뒀으면 그대로 둡니다.
  - **칸을 열면 그 줄의 팔레트로 자동 전환**됩니다. 곁줄 칸을 여는데 시김새 창이 열려 있으면 거기서 고른 기호가 그 칸에 들어가지 않아 헛클릭이 되므로, '지금 열린 팔레트로는 이 칸에 넣을 수 없다'면 알맞은 팔레트로 갈아 끼웁니다(율명·시김새는 둘 다 선율 줄이라 그대로 유지 / 빠르기·각·장·텍스트·정간 서식 창은 기호를 넣는 창이 아니라 건드리지 않음).
  - **곁줄은 더블클릭**으로 엽니다(정간 드래그 선택과 헷갈리지 않게). 곁줄이 아직 없을 때도 정간 오른쪽 빈 자리를 더블클릭하면 그 자리에서 곁줄이 시작됩니다.
- **기능바는 기본으로 왼쪽 세로 사이드에 도킹**되어 있습니다(위치 전환 버튼으로 악보 위 가로 배치와 오갈 수 있음 — 16장 참고).
- 기능바의 **입력** 그룹 다섯 버튼으로 뜬 도구창을 열고 닫습니다(한 번에 하나). 도구창은 그 버튼을 다시 누르거나, **창 오른쪽 위 ✕(닫기)** 버튼으로 닫을 수 있습니다.
- 팔레트를 클릭하면 지금 열려 있는 칸에 바로 들어갑니다.
- **시김새 숫자 단축키**: 붙임표 시김새 칩에 숫자(1~0) 배지가 항상 붙어 있습니다. **숫자키를 누르고 있는 동안** 악보의 음을 클릭하면 그 옆에 바로 붙고, 키를 떼면 해제됩니다. 여러 음에 연달아 붙일 땐 **칩을 클릭**하면 고정(다시 누르면 해제되는 켜기/끄기)됩니다. 배정은 시김새 보기의 **① 단축키 변환**에서 바꿉니다.
- **정간 구간 복사·오려두기·붙여넣기**(`⌘/Ctrl+C·X·V`): 악보에서 드래그로 고른 정간 구간이 대상이고, 그 정간에 **보이는 것 전부**(선율·곁줄·정간 서식=배경색·가로줄)가 함께 옮겨집니다. 붙여넣기는 고른 구간의 **첫 칸부터** 덮어쓰고, 악보 끝을 넘는 몫은 버립니다(각을 새로 만들지 않음). 장단은 곡에 한 줄뿐이라 대상이 아닙니다. 버튼 없이 단축키로만 씁니다.

### 입력 그룹 다섯 버튼 — 차례는 '정간에서 멀어지는 순서'

| 버튼 | 창 | 자리 |
|---|---|---|
| **井 율명/시김새** | 한 창 안에서 창 머리의 `율명 \| 시김새`로 갈아 끼움 | 정간 **안** |
| **傍 곁줄** | 노랫말·활 기호·장구 구음 | 정간 **바로 오른쪽** |
| **長 장단** | 장구 장단 | 곡에 하나뿐인 별도 줄 |
| **章 빠르기/각/장** | 빠르기 표기 · 각·장 이름 | 각 **위** |
| **文 텍스트** | 제목·부제 서식 · 자유 텍스트 | 종이 위 아무 곳 |

정간 서식은 '입력'이 아니라 **정간 편집** 그룹의 `□ 정간 서식` 버튼입니다(9장) — 井이 정간 **안에 넣기**라면 □는 정간 **자체를 꾸미기**입니다.

## 3. 선율 입력

### 텍스트 문법

정간 입력 카드에서 쓰는 문법입니다. 줄바꿈·`|`은 곡 전체를 한 텍스트로 다루는 (지금 숨겨진) 에디터 모드의 문법이고, **입력 카드에서는 한 정간 안의 문법**(분박·붙임·시김새 괄호 등)만 쓰면 됩니다.

| 문법 | 의미 |
|---|---|
| 줄바꿈(⏎) | **각**(세로줄, 마디) 구분 *(에디터 모드)* |
| `\|` | **정간**(칸, 1박) 구분 *(에디터 모드)* |
| 정간 안 공백(스페이스) | **분박** — 그 칸 안에서 위→아래로 줄이 나뉨(2·3분박 등 박 등분) |
| 공백 없이 이어 쓰기 | **붙임** — 한 분박(행) 안에서 왼→오른쪽 가로 배치 |
| 한글 율명 | 황·대·태·협·고·중·유·임·이·남·무·응 (12율) |
| 옥타브 접두어 | 청(+1) · 중청/겹청(+2) · 배/탁(−1) · 배탁/하배(−2). 없으면 중성 |
| `-` | 이음(연음) — 앞 음을 지속 |
| `쉼` / `쉼표` | 쉼표(무음) |
| 음 뒤 `<` | 숨표 — 그 정간의 오른쪽-아래 모서리에 고정 표시 |
| `{이름}` `[이름]` `(이름)` | 시김새 삽입 — 세 괄호 모두 동일하게 동작. 예: `황{미는표}` |
| `{이름@크기,좌우,상하}` | 시김새 개별 크기·위치 조정(4장 참고) |

- 격자는 입력된 `|` 개수가 아니라 **"한 각의 정간 수" 설정을 기준**으로 항상 온전히 그려집니다(빈 칸은 빈 채로 유지).
- 예: `황 태|협<|임` = 정간 3개 — 1번째는 황·태 분박, 2번째는 협+숨표.
- 곁줄·장단도 같은 문법을 쓰지만, 직접 입력에서는 칸을 눌러 그 칸의 내용만 적습니다(두 창의 텍스트 입력칸은 에디터 모드 전용이라 지금은 보이지 않습니다).

### 율명 팔레트

| 설정 | 내용 |
|---|---|
| 표 / 건반 | **표**: 음역(하배~중청) × 12율 매트릭스. **건반**: 피아노 건반 위 율명(클릭 입력 + 미리듣기) |
| 특수 줄 | 표 **위**에 한 줄 — 쉼표·이음(`-`)·숨표(`<`) + 표에 자리가 없는 특수 율명(거문고 하하배임 등). 칩은 12율 표와 같은 공식(위=악보에 찍히는 모양, 아래=타이핑할 글자) |
| 조 | 12율 전체 / 황종 평조 / 황종 계면조 / 중려 평조 — 그 조의 구성음만 모아 표시 |
| 표기 | 한자(黃·太…) / 한글(황·태…) — 팔레트와 악보 렌더에 동일 적용 |
| 황 음고 | E♭4 / C4 — 팔레트 클릭 소리·건반·악보 재생에 함께 적용 |
| 입력 토글 | 끄면 클릭해도 입력되지 않고 소리만 들려줌 |
| 소리 토글 | 클릭 시 그 음을 짧게 들려줄지 |
| 크기 −/＋ | 팔레트 표시 크기(시김새 팔레트와 따로 조절) |

### 율명 표기 규칙
- **한자 모드**(기본): 옥타브가 있으면 변형 한자(청황=潢 등)를 우선 쓰고, 변형자가 없는 조합(하배이·중청대)만 기본 한자 + 옥타브 점(●)으로 옅은 회색 표시. ±2옥타브까지 지원.
- **한글 모드**: 접두어+한글 그대로. 2글자 68%, 3글자 50%로 자동 축소되어 칸을 넘지 않습니다.
- 악보의 율명 글자만 기본보다 1.15배 크게 그려지고, **율명 크기** 슬라이더(기능바, 0.7~2.5×)로 전체 조절— 시김새 크기는 이 배율을 타지 않습니다.

### 이음(-) 전용 메트릭 (전통 관행)
- 분박 여러 줄 중 **한 줄에 `-`만 홀로** 있으면 그 줄의 세로 비중을 0.68로 줄여 낮게 누르고, 남는 공간을 음표 줄들이 나눠 가져 가운데로 모입니다. `-` 글자도 0.85배로 살짝 작게.
- `-`는 어디서든 가로로 1.95배 늘여 그려 짧아 보이지 않게 하고, 글리프가 낮게 찍히는 것을 감안해 살짝 위로 올려 세로 중심을 맞춥니다.
- 정간에 음이 정확히 둘일 때(세로 분박이든 가로 붙임이든)는 간격을 20% 좁혀 헐렁해 보이지 않게 합니다.

## 4. 시김새 (89종)

**井 율명/시김새** 창에서 창 머리의 `율명 | 시김새` 토글로 갈아 끼워 씁니다(버튼·창이 하나 — 둘 다 정간 안에 들어가는 것이라서). 팔레트 크기(±)는 **율명 보기와 시김새 보기가 각자 값을 따로 기억**합니다.

구성은 팔레트 네 묶음입니다.

| 묶음 | 수 | 자리 |
|---|---|---|
| 붙임표 | 64 | 음표 오른쪽에 작게 (미는표·흘림표·농음표 등) |
| 독립 기호 | 18 | 정간 한 칸을 통째로 차지 (전성·자출 등) |
| 운지 | 붙임표에 포함 | 음표 오른쪽에 작게 — 별도 묶음으로 모아 보여줌 |
| 빠르기 | 5 | 정간 **바깥 오른쪽**에 세로로 (본래속도로·점점느리게·점점속하게·조금느리게·조금속하게) |

퇴성·추성 2종은 붙임표·독립 기호 **양쪽**으로 쓰입니다. 따라서 세는 방식은 **시김새 84종**(붙임표 64 + 독립 18 + 양용 2)이고, 여기에 성격이 다른 **빠르기 기호 5종**을 더해 팔레트가 89칸입니다. 곁줄 기호 27종·장구 구음 7종은 다른 줄의 것이라 이 수에 들지 않습니다(사전 전체는 103항목).

이름 미상 시김새 23종은 정식 이름이 정해지기 전까지 임시로 `s01`~`s25`(09·19 없음)로 표시합니다(토큰도 `{s11}` 꼴 — 이름이 정해지면 표시 이름만 바뀝니다).

- 넣는 법 3가지:
  1. **팔레트 클릭** — 지금 열린 칸에 바로 들어갑니다.
  2. **글자로 입력** — 음 뒤에 `{미는표}`·`[미는표]`·`(미는표)` (세 괄호 동일). 팔레트 맨 위 한 줄 안내가 그 줄의 문법과 보기를 늘 보여주고, 칩 툴팁이 `→ {미는표}`처럼 실제로 들어가는 글자를 알려 줍니다.
  3. **숫자 단축키** — 2장 참고.
- **검색·최근**(칩이 12개를 넘는 줄 = 시김새·곁줄에만 붙습니다):
  - 검색칸 `이름·초성·악기로 찾기 ex) 모지, ㅁㅈ, 가야금` — 표시 이름·파일 이름에 더해 **한글 초성**과 **악기 이름**으로도 걸립니다(`Esc`나 ×로 지우기). 89개를 눈으로 훑기 어려워 둔 길입니다.
  - **최근** 줄에 방금 쓴 기호가 최대 10개까지 쌓입니다(줄별로 따로, 문서 상태로 저장).
  - 검색칸을 누르면 편집 중이던 칸이 닫히지만, 기호를 고르면 **그 칸을 다시 열어** 넣어 줍니다.
- **빠르기 기호 5종**은 정간 배치에서 빠져 **정간 바깥 오른쪽**에 세로로 그려지고, 다른 시김새와 똑같이 **끌어서 옮기고 크기를 고칠 수 있습니다**(숫자 단축키에서는 제외).
- **시김새 편집(위치·삭제) 모드**(시김새 보기의 ⌖ 버튼): 켜면 악보의 조절 가능한 시김새에 옅은 네모가 표시되고, 클릭하면 **고른 기호 옆에** 작은 패널이 떠서 **크기(40~300%)** 를 조절합니다. 위치는 패널 버튼이 아니라 **악보에서 기호를 직접 끌어** 옮깁니다(±90%). "위치·크기 초기화"와 "삭제"(Backspace/Delete 키로도) 제공. 팔레트 클릭·창 전환 같은 **다른 조작을 하면 저절로 꺼져서** 켜둔 걸 깜빡하고 엉뚱한 곳을 만질 일이 없습니다.
  - 패널은 기본적으로 기호 **왼쪽**에 뜹니다(정간보는 오른쪽→왼쪽으로 읽으니 왼쪽이 아직 안 읽은 쪽이라 덜 가림). 자리는 고를 때 한 번만 잡혀 크기를 조절하는 동안 달아나지 않습니다.
  - 이 모드에서도 **곁줄 더블클릭은 살아 있습니다**(모드를 끄고 그 칸을 엽니다).
- 조정값은 선율 텍스트에 `{이름@크기,좌우,상하}`로 저장됩니다(예: `황{미는표@120,5,-5}` = 120% 크기, 오른쪽 5·위 5 이동). 기본값(100,0,0)이면 이름만 남습니다.
- 시김새는 "율명 크기" 슬라이더의 영향을 받지 않아 음표만 키워도 시김새는 그대로입니다.
- **악기 선택**(팔레트 머리줄): 가야금·거문고·대금·피리·해금·아쟁 중 고르면 그 악기에서 자주 쓰는 시김새가 **각 묶음 안에서** 맨 앞으로 올라옵니다(묶음 구분은 유지). 곁줄 기호 팔레트에도 같은 우선순위가 적용되고, 선택은 문서 상태로 저장됩니다.
- 인쇄·PNG에는 편집 모드의 네모가 찍히지 않습니다(모드를 켜 둔 채 출력해도 안전).

## 5. 장단(장구) 입력

- 장단 창 머리의 체크박스를 켜면 활성화됩니다(새 문서 마법사에서도 선택 가능). **각 하나를 통째로 차지하는 줄이라 켜고 끄는 스위치가 남아 있는 유일한 레이어**입니다(곁줄은 6장 참고).
- 팔레트 7종: **덩 · 작은덩 · 기덕 · 궁 · 덕 · 다 · 더러러러**. 칸을 눌러 이름을 그대로 적거나 팔레트를 클릭하며, 한 칸 안에서 공백으로 분박을 나눕니다.
  - 장단 줄은 **괄호가 선택**입니다 — 전부 구음이라 `덩`처럼 이름만 써도 되고, 다른 줄 버릇대로 `{덩}`이라 씌워도 벗겨 읽습니다. 7개뿐이라 검색·최근 없이 칩만 한 격자로 나옵니다.
- 장단은 반복 패턴이므로 **곡 맨 처음 각(가장 오른쪽) 옆에 한 번만** 표시되고, 일반 각과 같은 폭을 차지합니다(첫 각이 그만큼 왼쪽으로 밀림). 정간 수는 선율과 자동으로 맞춰집니다.
- 장단 각은 **네 변을 일반 각보다 조금 굵은 선**으로 둘러 율명 각과 한눈에 구분되고, 각 아래(각 번호 자리)에 옅은 회색 **'장단' 라벨**이 붙습니다 — 각 번호 표시 설정과 한 세트로 켜지고 꺼집니다.
- '다'는 원본 기호가 작은 점이라 다른 구음보다 훨씬 작게(장단 줄에서 0.15배) 그려집니다 — 실물 악보 비율. 팔레트 칩에서도 같은 비율로 줄여 보여줍니다.
- **장단 입력** 줄 오른쪽 끝의 **초기화** 버튼으로 장단만 비울 수 있고, ⌘/Ctrl+Z로 복구합니다.

## 6. 곁줄 (가사·활·구음)

**정간 오른쪽에 붙는 좁은 줄**의 이름입니다(기능바 `傍 곁줄`, 창 머리 부제 '가사·활·구음'). 내용으로 이름을 지으면 들어오는 것이 늘 때마다 이름을 고쳐야 해서(가사 → 가사/활 → 가사/활/구음 …) **자리로** 지었습니다 — 정간 안이 '무엇을 소리내나'라면 곁줄은 '그 소리에 곁들이는 것'(부르는 말·손이 하는 일·함께 치는 북)입니다.

- **켜고 끄는 스위치가 없습니다.** 내용이 있으면 늘 나오고(인쇄·PNG 포함), 내용이 없어도 **곁줄 창이 열려 있으면 화면에 빈 줄이 보입니다**(더블클릭해 첫 글자를 넣을 자리가 생기게). '쓸까 말까'를 미리 정하게 하던 예전 체크박스는 없앴습니다.
  - 곁줄이 아직 없을 때도 **정간 오른쪽 틈을 더블클릭**하면 그 자리에서 시작할 수 있습니다.
- 선율과 같은 구조 — 줄바꿈 = 각, `|` = 정간, 정간마다 한 글자(또는 여러 자)를 적으면 **그 정간의 오른쪽에 딱 붙은 칸**에 표시됩니다. 곁줄이 생겨도 **각 사이 간격은 변하지 않습니다** — 곁줄이 원래 간격 안에 들어가므로 한 줄에 놓이는 각 수에도 영향이 없습니다.
- **글씨체** 선택(창 머리줄 오른쪽): 궁서체(붓글씨)·고딕체·명조체·애플고딕·해서체.
- **글자 크기**는 기능바의 **곁줄 크기** 슬라이더(0.7~2×)로 조절합니다 — 곁줄이 나와 있을 때만 보입니다.
- **기호 팔레트**(창 안 팔레트, 묶음 둘): 클릭하면 편집 중인 곁줄 칸에 `{기호}` 토큰이 한 글자처럼 들어가고, 악보엔 이미지로 그려집니다. **곁줄은 괄호가 필수** — 글자를 적는 자리라 괄호 없는 `덩`은 그냥 '덩' 글자입니다.
  - **기호 20종**: 가로표·세로표·늘임표·뜰·모지·장지·튕김·연튕김 8종 + 전성·퇴성·추성(시김새와 같은 그림) 3종 + 운지 s01~s08·s10 9종.
  - **장구 7종**: 덩·작은덩·기덕·궁·덕·다·더러러러 — 장단 줄이 없는 악보에서 구음을 정간 옆에 적는 쓰임. 성격이 달라(가락 기호 vs 북 소리) 한 격자에 섞지 않고 따로 묶습니다.
  - 시김새와 **같은 팔레트 빌더**라 칩 모양·검색·최근이 똑같습니다(검색: 이름·초성·악기).
  - 구음처럼 한 글자로 읽히는 기호는 서로 키가 같도록 정사각 상자에 넣어 그립니다(세로로 긴 기호만 유난히 커지지 않게). 가로표·세로표 같은 '표'류는 칸을 가로지르는 게 제 노릇이라 그대로 둡니다.
  - 한 분박에 토큰이 여럿(`{모지}{퇴성}`)이면 **옆이 아니라 위아래로** 살짝 붙여 쌓이고, 각각의 크기는 단독일 때와 같습니다.
  - 기호 크기는 글자처럼 **분박 수와 무관하게 고정** — `{튕김} - {전성}`처럼 행이 늘어도 줄지 않습니다.
- 각 수·정간 수는 선율과 1:1 — 각을 추가/삭제하면 곁줄도 같이 밀리고 당겨집니다. 타이핑 중 선율과 각 수가 어긋나면 경고 배너가 떠서 알려줍니다(장단도 정간 수 어긋남 경고 동일).
- 창 머리줄 오른쪽 끝의 **초기화** 버튼으로 곁줄만 비울 수 있습니다(⌘Z 복구).

## 7. 텍스트 (자유 주석 · 제목/부제 서식)

창의 짜임은 **章(빠르기/각/장) 창과 같습니다** — 전역 설정은 머리줄, 항목은 목록. 이 두 자리만 씁니다.

- 맨 위 **추가 줄**에 내용을 적고 **추가**를 누르면 목록에 줄이 늘어나고 악보 위에 얹힙니다.
- 목록은 **제목 → 부제 → 자유 텍스트** 순으로 한 줄에 한 항목씩 놓입니다.
  - **제목·부제**는 곡에 하나뿐이라 목록 맨 위에 고정으로 서고, **내용이 비면 목록에서 사라집니다**. 내용 칸은 **설정 › 문서 탭의 제목·부제와 같은 값**(양방향 연동)입니다.
  - 제목 항목: 내용 · 방향(**세로 칸 / 가로 위**) · 크기(2~30mm) · 자간(−5~30mm) · **칸 폭**.
  - 부제 항목: 내용 · 크기(1~20mm) · 자간.
  - 자유 텍스트 항목: 내용 · 방향(세로/가로) · 크기 · 자간 · 글자 색 · 삭제.
- **칸 폭**(세로 칸 제목 전용): `자동 / 1각 / 2각 / 3각 / 4각` — **세로 칸 제목이 첫 줄에서 차지하는 각 자리 수**를 정합니다. 넓게 잡으면 그만큼 첫 페이지에 들어가는 각이 줄고, 각 너비는 종이에 맞춰 자동으로 다시 잡힙니다(mm가 아니라 각 단위로만 움직여 격자 정렬이 유지됩니다). '가로 위' 제목에는 뜻이 없어 숨습니다.
- **제목·부제·자유텍스트는 이 텍스트 창이 열려 있을 때만** 악보에서 점선 상자로 하이라이트되고 끌 수 있습니다(章 창과 같은 규칙). 창을 닫으면 정적 표시.
- **위치는 악보에서 직접 끌어** 옮기고(상하/좌우 숫자 칸은 드래그가 대신 쓰는 값이라 UI에서 숨김), 클릭하면 작은 패널이 떠서 크기 ±와 삭제를 할 수 있습니다.
- 텍스트 창은 목록이 길어져도 **내부 스크롤 없이 쭉 다 펴서** 보여줍니다.
- **글씨체**는 머리줄에 있습니다 — 제목·자유 텍스트에 한꺼번에 걸립니다(부제는 제목을 따름).

## 8. 빠르기 / 각·장 (각 위 표기 — 一分・六十井 · 1장·대여음 등)

기능바 **章 빠르기/각/장** 창이 맡는 두 가지 — **각 위 이름표**(1장·대여음 등)와 **빠르기 표기**입니다. 이름표는 자유 텍스트와 달리 **각에 소속**되어 각을 따라다니고(각 삽입/삭제·페이지 이동 포함), 둘 다 인쇄·PNG에 표시되는 악보 내용입니다.

### 각·장 이름 (1장 · 대여음 등)

- **넣는 법 2가지**:
  1. 악보에서 **각 위의 빈 부분을 클릭** → 그 자리에 입력 카드 (`Enter` 확정, `Esc` 취소, 비우고 확정하면 삭제).
  2. 창의 추가 줄에서 각 번호와 이름을 적고 **추가**. 창의 목록에서 수정·삭제도 합니다.
- **한자 자동 표기**: 입력은 한글 그대로 저장되고 악보 표기만 바뀝니다.
  - `1장`·`2장`처럼 쓰면 → **一章·二章** 꼴 한자로.
  - **대여음·중여음·여음·환입·초장·종장**도 한자(大餘音 등)로. 그 밖의 단어는 쓴 그대로.
- **일괄 크기·간격**(창 머리줄): 크기(×)는 모든 각/장 이름 글자에 한 배율로 — 기준이 '맨 아래 글자'라 크기를 키워도 **위로만** 자랍니다. 간격(mm)은 각 위쪽 선과 맨 아래 글자 사이 거리.
- 위 공간이 모자라면(긴 이름·페이지 위 여백) 잘리지 않게 글자가 자동으로 줄어듭니다.
- **각 위의 빈 부분 클릭으로 이름 카드가 열리는 것은 이 창이 열려 있을 때만**입니다(늘 살아 있으면 위쪽 여백·제목 근처를 누를 때마다 카드가 불쑥 열립니다). 이름 글자 자체를 끌거나 누르는 길은 창과 무관하게 살아 있습니다.

### 빠르기 표기 (一分・N井)

- **빠르기 체크**(창 머리줄): 켜면 맨 처음 각(장단이 있으면 장단 칸) 위에 `一分・六十井` 식 표기가 나오고, **목록 맨 위에 '빠르기' 항목이 하나 생깁니다**(곡에 하나뿐이라 각에 소속되지 않음).
- 항목의 칸들: **미리보기**(`一分・六十井` — 지금 만들어지는 실제 표기) · **BPM**(최소, 20~240) · **~**(최대, 비우면 한 값만) · **크기**(×) · **자간**(mm).
  - **범위로 적을 수 있습니다** — 최대를 비우면 `一分・六十井`, 채우면 `一分・六十～八十井`(물결표는 전각 `～` — 반각은 세로쓰기에서 가는 획으로 묻힙니다). 최대가 최소보다 작으면 범위로 치지 않습니다.
  - 한자 수사는 국악보 관행대로 **백의 자리에서 `百`을 뺍니다**(160 → `一六十`, 180 → `一八十`). 딱 떨어지는 백(100·200)만 `一百`·`二百`입니다. 각/장 이름의 한자 변환(N장→N章)은 표준 표기를 그대로 씁니다.
  - **자간**은 세로쓰기 글자 사이를 벌립니다(고정 mm). 표기가 각 위 여백을 넘지 않도록 남는 높이까지만 벌어집니다.
  - **크기·자간 모두 그 항목에서 각/장 이름과 따로** 조절합니다 — 각/장 이름은 여러 개를 머리줄 값으로 한꺼번에 맞추지만, 빠르기는 곡에 하나뿐이라 제 항목에서 바로 조절합니다.
  - 빠르기 표기를 키우면 그만큼 위 공간을 쓰므로 정간이 조금 작아질 수 있습니다 — 배율을 올릴수록 커지긴 하지만 정비례로 커지지는 않습니다.
- **재생 BPM과는 따로 갑니다**: 재생(⚙)의 BPM은 처음엔 표기의 **최소값**을 따르지만, 재생 설정에서 한 번이라도 직접 바꾸면 그때부터 표기를 고쳐도 끌려가지 않습니다(표기가 범위일 때 '재생은 어느 쪽 값인가'에 답이 없어서). 12장 참고.
- **위치는 좌우·상하 모두 악보에서 끌어서** 정합니다 — 숫자 칸으로 내놓지 않았습니다(끌기와 하는 일이 겹쳐 헷갈렸습니다).
- **하이라이트**: 이 창이 열려 있는 동안 악보의 각/장 이름·빠르기 표기에 **점선 상자**가 씌워져 어떤 것들이 이 창 소관인지 한눈에 보입니다(인쇄·PNG엔 안 나옴).
- **드래그 이동**: 악보에서 각/장 이름을 **직접 끌어** 위치를 옮길 수 있습니다(이름별 오프셋으로 저장, 각 삽입/삭제 때 이름과 같이 밀림). 움직이지 않고 클릭하면 기존처럼 이름 입력 카드가 열립니다.
- 각 번호는 사이드바의 **각 번호 표시**(기본: 화면에만)를 켜 두면 바로 확인할 수 있어 짝을 이룹니다.

### 정간 서식 (배경색·정간·가로줄)

기능바 **정간 편집** 그룹의 **□ 정간 서식**으로 엽니다. 창이 열려 있는 동안은 **정간 선택 모드** — 악보의 정간을 **클릭하면 한 칸, 드래그하면 여러 칸**이 선택되고(내용 편집 카드는 열리지 않음), 실행 버튼을 눌러 적용합니다. 창 머리에 `악보에서 정간을 클릭(한 칸)·드래그(여러 칸)로 고른 뒤 누르세요`가 상시로 적혀 있고, 고른 것이 없으면 버튼이 비활성화됩니다. 창을 닫으면 클릭=내용 편집으로 돌아갑니다. (현재 선율 정간에만 적용 — 장단·곁줄 칸은 미지원)

섹션은 **배경색 / 정간 / 가로줄** 셋 + 맨 아래 초기화입니다.

#### 배경색

| 기능 | 내용 |
|---|---|
| **색상 + 칠하기** | 왼쪽 색판에서 색을 고르고 **칠하기**를 누르면 고른 정간이 그 색으로 칠해집니다. 색판은 '지금 칠할 색'일 뿐이라, 골라도 누르기 전엔 아무 일도 없습니다(여러 색을 번갈아 칠할 수 있게) |

#### 정간

| 기능 | 내용 |
|---|---|
| **합치기** | 정간 두 칸 이상을 고르고 누르면 고른 칸들 *사이* 줄이 사라져 한 칸처럼 보입니다. 고르지 않은 칸과 맞닿은 바깥 줄은 그대로 남습니다. **나누기**로 되돌립니다.<br>· 악보 뼈대(맨 위·아래 통줄, 대강선)는 숨기지 않습니다 — 대강 경계를 넘어 합치면 그 자리 굵은 선은 남습니다 |
| **없애기** | 고른 자리의 정간을 통째로 지워 **빈 자리**로 만듭니다 — 좌우 벽과 칸 사이 줄이 사라집니다.<br>· 위아래 이웃과 맞닿은 가로줄은 남습니다. 그 줄은 이웃 칸의 벽이기도 해서, 같이 지우면 멀쩡한 이웃 정간이 열려버립니다<br>· 한 칸만 골라도 됩니다(합치기와 달리)<br>· 정간 내용(음·시김새)은 그대로 — 지우려면 **내용 지우기**를 쓰세요 |

#### 가로줄

| 기능 | 내용 |
|---|---|
| **방향** | **위** / **아래** — 아래 모양 버튼이 고른 정간의 어느 가로줄에 적용될지. 둘 중 하나는 늘 켜져 있습니다.<br>· 좌우(각의 벽)는 손대지 않습니다 — 칸마다 따로 바꿀 일이 없어서 |
| **모양** | **굵게** / **점선** / **이중선**(바깥 줄은 '보통' 굵기, 안쪽에 한 줄 더) — 누르면 고른 정간에 바로 적용. 모양마다 굵기가 정해져 있습니다.<br>· **굵게**는 악보 맨 위·아래 통줄과 같은 두께입니다 — 원래 있던 굵은 가로줄처럼 보이도록. 좌우 세로선을 넘지 않고 딱 맞게 끝납니다 |

#### 초기화

창 맨 아래 **초기화**는 고른 정간에 해둔 서식을 **모두** 물립니다 — 배경색·테두리(굵게·점선·이중선)·합치기·없애기가 한 번에 지워져 원래 격자로 돌아갑니다(위/아래 선택과 무관하게 네 변). 정간 내용(음·시김새)은 그대로입니다. 버튼 아래에 `배경색·가로줄을 함께 지웁니다`가 상시로 적혀 있습니다. 지우개는 이 하나뿐입니다('색 지우기'와 '테두리 지우기'로 갈려 있던 것을 합쳤습니다).

### 출력 — 상단바 (인쇄 버튼 · ⋯ 파일 메뉴)

출력·보관 **명령은 모두 상단바**에 있습니다. 사이드바를 접어둔 채로도 바로 쓸 수 있습니다.

- **인쇄 / PDF 저장** — 상단바의 **인쇄** 버튼(프린터 그림). 브라우저 인쇄창이 열리고, 화면 전용 UI는 모두 숨겨져 악보만 페이지별로 출력됩니다. **PDF로 저장하면 기본 파일명이 곡 제목**이 됩니다(⌘/Ctrl+P로 인쇄해도 동일).
- **PNG 다운로드** — ⋯ **파일** 메뉴. 페이지별 SVG를 300dpi 기준으로 렌더해 저장. 여러 장이면 `제목-1.png, 제목-2.png…`로 나뉨.
- **파일로 저장 / 불러오기** — ⋯ **파일** 메뉴. 문서 전체(설정+선율+곁줄+장단+텍스트+정간 서식)를 `.jgb.json` 파일로 내보내고 다시 불러옵니다. **다른 컴퓨터로 옮기거나 남에게 보낼 때는 이 방법**을 씁니다. 문패 옆 **BETA 배지** 팝오버의 '지금 파일로 저장'도 같은 명령입니다.
- **링크 복사** — ⋯ **파일** 메뉴. 악보 전체를 압축해 담은 **주소(URL)** 를 복사합니다. 링크를 받은 사람이 열면 그 사람의 브라우저에서 이 악보가 그대로 열립니다(서버·계정 불요 — 주소 자체에 악보가 담깁니다). 곡이 아주 크면 링크가 길어질 수 있어 파일 공유를 권하는 안내가 뜹니다. 링크를 열 때 작업 중이던 악보가 있으면 물어본 뒤 '보관' 탭에 자동 저장하고 바꿉니다.
- **악보 게시** — ⋯ **파일** 메뉴. 악보를 서버에 올리고 **짧은 주소**(`umulsai.com/#v=ab12cd34`)를 받습니다. 링크 복사와 하는 일은 비슷하지만 두 가지가 다릅니다: 주소가 짧아 **메신저에서 잘리지 않고**, 올린 뒤에도 **같은 주소로 고칠 수 있습니다**.
  - 올릴 때 **지은이**(선택)와 **이용 조건**(저작권 유보 · CC BY · CC BY-NC · CC BY-SA · CC0)을 함께 적습니다. 남의 채보·편곡을 그대로 올리지 않도록 권리 확인에 한 번 표시해야 게시됩니다.
  - **모아보기 목록에 올리기**가 기본으로 켜져 있습니다. 끄면 **주소를 아는 사람만** 볼 수 있습니다(목록에 오르지 않습니다).
  - 카드에 쓸 **미리보기 그림은 올릴 때 자동으로 만들어집니다**(악보 첫 장).
  - **저작권이 살아 있는 곡(가요·팝송·영화음악 등)을 옮긴 악보는 올릴 수 없습니다.** 정간보로 바꾸는 일도 저작권법에서는 복제·편곡입니다. 자세한 것은 [이용약관 및 저작권 정책](../policy.html).
  - 남이 올린 악보를 열면 위 알림 줄에 **신고** 링크가 있습니다. 신고가 들어오면 확인 즉시 내리고, 무엇을 왜 내렸는지 [중단 내역](../notices.html)에 남깁니다.
  - **수정·삭제 열쇠는 이 브라우저에만 저장됩니다.** 브라우저 저장 자료를 지우거나 다른 컴퓨터에서 열면 그 악보를 고칠 수 없습니다(계정이 없어 되찾을 방법이 없습니다). 중요한 악보는 `.jgb.json`으로도 저장해 두세요.
  - 이미 올린 악보를 다시 열면 같은 메뉴가 **갱신**·**새로 게시**·**이 게시물 내리기**로 바뀝니다.
  - 남이 올린 악보를 열어 고친 뒤 게시하면 **새 주소**로 올라가고, 원래 악보가 출처로 기록됩니다. 원본은 바뀌지 않습니다.
- **전체 초기화** — ⋯ **파일** 메뉴 맨 아래(빨간 글씨). 내용만 지우고 레이아웃은 남깁니다. 누르면 한 번 더 묻고, 되돌리기(⌘Z)로도 취소됩니다.

### 모아보기 (사람들이 올린 악보)

상단바 오른쪽 **모아보기** 버튼을 누르면 공개로 올라온 악보를 모아 보는 페이지가 열립니다(`umulsai.com/browse.html`).

- 카드에는 **악보 미리보기 · 제목 · 지은이 · 올린 때 · 이용 조건 · 본 횟수**가 보입니다. 다른 악보를 고쳐 만든 것은 **다른 악보에서** 표가 붙습니다.
- **최신순 / 많이 본 순**으로 정렬하고, **제목·지은이**로 찾을 수 있습니다.
- 오른쪽 위 버튼으로 편집기로 돌아갑니다. **편집하던 악보가 있으면 〈← 편집기로 돌아가기〉**, 없으면 〈악보 만들기〉로 보입니다(가는 곳은 같습니다).
- 카드를 누르면 그 악보가 편집기에서 그대로 열립니다. **고쳐도 원본은 바뀌지 않습니다** — 고친 것을 다시 올리면 새 주소로 올라가고, 원래 악보가 출처로 기록됩니다.

### 보관 탭 (사이드바)

- **임시 저장 (이 컴퓨터)** — 이름을 적고(비우면 제목·시간) 저장하면 목록에 쌓이고 언제든 되불러옵니다(불러오기는 ⌘Z로 취소 가능). 이 컴퓨터 브라우저 안에만 남는 저장입니다.

### 레이아웃 탭의 요약(readout)

그린 각 수·페이지 수·가로 각/세로 밴드·실제 각 너비와 간격(mm)·A4 맞춤 축소율·읽는 순서를 항상 보여줍니다. 레이아웃 값을 바꾼 결과가 바로 여기 나타납니다.

## 11. 저장 체계 한눈에

| 방식 | 언제 | 어디에 | 특징 |
|---|---|---|---|
| 자동 저장 | 입력할 때마다 즉시 | 브라우저 `localStorage` | 새로고침해도 유지. 따로 누를 것 없음 |

## 12. 재생 (사인파 + 장구 소리)

- 상단바 오른쪽의 재생 컨트롤: **▶ 재생** 버튼 하나가 상태에 따라 **⏸ 일시정지 → ▶ 이어하기**로 바뀌고, 옆에 **■ 정지**와 ⚙ 설정이 있습니다.
- 설정: **황 음고**(E♭4 기본 / C4 — 팔레트의 황 음고와 연동) · **템포**(BPM 20~240, 기본 60) · **장구 소리**(기본 켬) · **시김새대로 연주**(기본 켬).
- **여기 BPM은 재생(미리듣기) 전용**입니다 — 처음엔 악보에 적은 빠르기의 **최소값**을 따르고, 여기서 한 번이라도 바꾸면 그때부터 따로 갑니다. 악보에 남는 빠르기 표기는 **章 빠르기/각/장 창**에서 정하며, 최소~최대 범위로도 적을 수 있습니다(8장 참고).
- 재생 규칙: 정간 1칸 = 1박, 분박은 등분, **빈 정간·이음(-)은 앞 음 지속**, **쉼표만 무음**.
- **시김새가 소리로 풀립니다.** 니·노 같은 기호는 **반음 위아래가 아니라 그 곡 음계의 이웃 음**으로 울립니다 — 음계는 조 프리셋이 정해져 있으면 그것을, '12율 전체'면 악보에 많이 나온 율명 다섯을 세어 정합니다. 음표에 붙는 시김새는 그 음 자리를 살짝 나눠 꾸밈으로 지나가고(박은 밀리지 않습니다), 한 칸을 차지하는 시김새는 그 자리를 나눠 실제로 울립니다.
  - 음높이를 옮기지 않고 **주법을 적는 표**(흘림표·미는표·요성표·추성·퇴성 등)는 사인파로 흉내 낼 것이 없어 소리가 없습니다(앞 음이 그대로 이어집니다).
  - **재생 설정 ⚙ › 시김새대로 연주**를 끄면 적힌 율명만 울리는 **민음**이 됩니다(가락의 뼈대만 듣는 자리). 오선보는 이 설정과 무관하게 그대로입니다.
- **장구 소리**: 장단 줄을 켜고 구음을 적어 두면 선율과 함께 실제 장구 소리(녹음 음원)가 납니다. 장단은 **한 각짜리 패턴**이라 곡 내내 각마다 되풀이되고, 칸 안 분박도 선율과 같은 규칙으로 박을 등분합니다. 이음(-)은 앞 소리를 잇는 표시라 새로 치지 않습니다. 소리를 끄려면 **재생 설정 ⚙ › 장구 소리**.
  - 소리가 있는 구음은 **덩·작은덩·기덕·궁·덕·다·더러러러** 일곱입니다(작은덩은 덩을 여리게 친 음원, 궁은 '쿵'과 같은 소리).
  - **기덕**처럼 앞꾸밈이 붙은 겹타는 음원을 박보다 **0.15초 먼저** 시작해, 본 타(덕)가 박에 떨어지게 맞춰 뒀습니다.
  - 음원은 **[재생]을 처음 누를 때** 불러옵니다 — 페이지를 열 때는 받지 않습니다.
- 재생 중 현재 정간이 악보에 하이라이트되고 끝나면 자동 정지.

## 13. 악기와 총보

한 문서 안에 **악기를 여럿 두고 한 악보에 나란히** 그릴 수 있습니다(총보). 악기가 하나뿐이면 예전과 똑같이 동작하므로, 쓰지 않으면 없는 기능이나 마찬가지입니다.

- **악기 관리 창**(사이드바 **문서** 탭 › `악기 관리…`): 악기를 더하고 지우고, 이름·악기를 정하고, 순서를 바꾸고, **지금 편집할 악기(◉)**를 고릅니다. 목록 순서가 곧 총보에서 열이 서는 순서입니다(목록 위가 오른쪽 — 읽는 방향).
  - **악기마다 따로**인 것: 선율 · 곁줄 · 정간 서식 · 시김새 우선순위 악기
  - **곡 전체가 함께 쓰는** 것: 레이아웃 · 장단 · 각·장 이름 · 자유 텍스트
  - 마지막 악기는 지울 수 없습니다(문서에는 늘 악기가 하나 이상).
  - **🔊/🔇**로 그 악기를 재생에서 뺄 수 있습니다.
- **새 문서 마법사에 악기 편성**이 있습니다. 비워 두면 예전처럼 악기 하나로 시작하고, 둘 이상 적으면 총보 보기로 시작합니다.
- **보기 전환**(상단바 배율 왼쪽 **보기** 메뉴): 악기가 둘 이상일 때만 나타나며, **총보**(전부 나란히)와 **각 악기의 파트보** 중에 고릅니다. 버튼 글씨가 지금 보기를 알려 줍니다. 파트보를 고르면 편집 대상도 그 악기로 함께 바뀝니다.
- **총보에서 남의 악기 열을 누르면 그 악기로 갈아타고 누른 칸이 곧장 열립니다**(정간은 클릭, 곁줄은 더블클릭). 편집·드래그 선택·정간 서식은 늘 **지금 편집하는 악기의 열에만** 적용됩니다.
- **인쇄·PNG는 보이는 그대로** 나갑니다 — 보기 전환이 곧 '총보로 뽑을지 파트보로 뽑을지'입니다(따로 고르는 곳이 없습니다).
- **레이아웃은 보기마다 따로 기억됩니다.** 레이아웃 탭의 배치·크기·간격·머리단·테두리와 종이 크기·방향은 총보와 파트보가 각자 값을 가지고, 문서 탭(정간 수·총 각 수·대강·제목)은 함께 씁니다. 총보에 처음 들어가면 한 줄 각 수를 악기 수로 나눠 잡아 줍니다.
- **재생은 합주입니다** — 악기들이 같은 시각에 함께 울립니다. 악보에 표시되는 현재 정간은 지금 편집하는 악기의 열에 나타납니다.

## 14. 오선보 (보기 · 내보내기)

정간보를 **서양 악보로 옮겨** 화면에서 바로 보거나 파일로 내보냅니다. **시김새가 실제 음높이로 풀려** 적히므로, 니·노 같은 기호가 어떤 음이 되는지 눈으로 확인할 수 있습니다.

- **오선보 보기**(상단바 배율 옆 오선 아이콘): 정간보 **아래에 칸이 열려** 오선보가 함께 뜹니다. 정간보를 고치면 곧바로 따라 바뀝니다.
  - **무엇을 보여줄지는 정간보의 보기 설정을 그대로 따릅니다** — 총보면 모든 악기를 오선 여러 줄로, 파트보면 지금 편집하는 악기만. 둘이 늘 같은 것을 보여야 나란히 놓고 견줄 수 있습니다.
  - 칸 머리줄에서 **정간 하나를 무엇으로 볼지**(점4분음표 · 4분음표 · 8분음표), **배율**(−/＋), **파일로**(MusicXML 저장)를 고릅니다. 칸 높이는 경계를 끌어 조절합니다.
  - **음의 길이는 자리로 보입니다** — 정간보의 분박은 5등분·7등분처럼 서양 음표값으로 딱 떨어지지 않는 것이 흔해, 음표 모양은 가장 가까운 것으로 그리되 **가로 자리를 실제 길이에 비례**해 놓습니다. 정확한 길이는 MusicXML 쪽이 지닙니다.
  - **각 하나가 한 마디**이고 각을 두 줄에 걸쳐 쪼개지 않습니다. 각이 창보다 넓으면 가로로 스크롤합니다.
  - 배율과 칸 높이는 **이 브라우저에** 기억되고(문서에는 저장되지 않음), 열어 둔 상태는 기억하지 않습니다.
  - **인쇄·PNG에는 정간보만** 나갑니다.
- **오선보 내보내기**(⋯ **파일** 메뉴): MusicXML 4.0 파일로 저장해 뮤즈스코어·피날레·시벨리우스에서 엽니다. 악기가 여럿이면 여러 파트로 나갑니다.
  - **정간 하나를 무엇으로 볼지**가 박자표를 정합니다 — 점4분음표면 각 정간 수 N에 대해 `3N/8`, 4분음표면 `N/4`. 취향이 아니라 **그 곡이 정간을 몇으로 쪼개느냐**에 달렸습니다. 3분박이면 점4분음표라야 분박이 8분음표로 딱 떨어지고, 2분박이면 4분음표(각이 길면 8분음표)라야 그렇습니다. 정악은 3분박이 흔해 **점4분음표가 기본**입니다.
  - 이 값은 **문서에 딸려** 다닙니다(악보를 남에게 주면 같이 갑니다). 반면 보기 배율·칸 높이는 이 브라우저의 보기 설정입니다.
  - 마디를 넘는 음은 잘라 **붙임줄**로 잇고, 마지막 마디의 빈자리는 쉼표로 채웁니다. 붙임 시김새는 **꾸밈음**으로, 제 칸을 차지하는 시김새는 그 자리를 나눈 실음으로 나갑니다.
  - **조표는 음계의 '도'에서 끌어냅니다** — 다섯 음짜리 음계는 임시표 없이 적을 수 있는 조표가 셋이라(황종 평조면 ♭5·♭4·♭3) 개수만으로는 고를 수 없습니다. 셋 다 같은 음을 적고 무엇을 '도'로 보느냐만 다르므로, 평조는 솔라도레미·계면조는 라도레미솔로 읽어 그 **'도'를 으뜸음으로 삼는 조표**를 고릅니다 — 황종 평조 ♭4(도=중려), 중려 평조 ♭5, 황종 계면조 ♭6(도=협종).
  - **장단과 곁줄(가사)은 아직 실리지 않습니다.**

## 16. 화면 보기·조작

- **마우스 모드**(기능바 맨 왼쪽): **선택**(화살표)은 정간을 클릭해 입력·편집하는 기본 모드, **이동**(손)은 악보를 잡고 끌어 화면을 움직이는 팬(pan) 모드입니다. 이동 모드에선 커서가 손 모양으로 바뀌고 실수로 편집되지 않게 악보 클릭이 잠깁니다(확대해 놓고 이리저리 볼 때 편함). 새로고침하면 선택 모드로 돌아옵니다.
- **보기 배율(줌)**: 상단바 오른쪽에 고정 — −/＋, **세로맞춤**(페이지 높이를 화면에), **가로맞춤**(페이지 너비를 화면에). 화면 표시만 바뀌고 출력 크기와는 무관.
- 뜬 도구창은 그립(⠿)을 끌어 원하는 자리로 이동(악보를 스크롤해도 그 자리에 떠 있음). 줌·재생 바는 상단바에 고정이라 끌 필요가 없습니다.
- 사이드바는 ✕로 접고 "설정" 버튼으로 다시 엽니다.
- 버튼에 마우스를 올리면 설명 말풍선이 뜹니다(화면 가장자리에서도 잘리지 않게 위치 자동 보정).
- 각 도구창 머리의 **?** 버튼: 그 창의 입력 방법·문법 안내(율명/시김새 창의 안내가 시김새까지 함께 다룹니다). 팔레트 맨 위에는 그 줄의 괄호 문법이 **한 줄로 늘 떠 있습니다**(예: `✎ 글자 그대로/괄호 안에 넣어 입력 가능 ex) 덩 · {덩}`).
- 전체 단축키 안내는 상단바 **도움말 → 단축키** 탭에 있습니다.
- 기능바는 **기본이 왼쪽 세로 사이드**입니다(맨 위 위치 전환 버튼으로 악보 위 가로 배치와 오감): 입력 버튼이 3:2로, 열린 도구창이 그 아래로 도킹되어 사이드바처럼 정리됩니다.
  - **폭 조절**: 도크와 악보 사이의 세로 알약 손잡이를 **끌면 열 폭이 조절**됩니다(최소 240px). **더블클릭하면 자동 폭**으로 복귀. 지정한 폭은 저장되어 유지됩니다.
  - 어떤 도구창을 켜도 열 폭이 같고, **시김새·곁줄·장단 기호 팔레트는 같은 빌더·같은 격자**라 열 폭에 맞춰 한 줄 개수가 자연스럽게 줄바꿈됩니다(기본 폭에서 6개/줄). 율명 표는 폭이 모자라면 표 안에서 가로 스크롤.
  - 율명 팔레트를 크기 ±로 키워도 열 폭은 그대로 — 커진 표는 팔레트 안 가로 스크롤로 봅니다. 크기 값은 **율명 보기와 시김새 보기가 따로** 기억됩니다.
- **색상(색상 테마·다크)**: 상단바 오른쪽 **해/달 아이콘 + 글자 '색상'** 버튼을 누르면 메뉴가 열립니다. 밝은 화면의 색조는 **미색(따뜻한 베이지) · 은청색(차갑고 맑은 톤) · 옥색(은은한 옥빛)** 세 테마에서 고르고(지금 쓰는 테마에 표시가 붙음), 맨 아래 항목으로 밝은 화면 ↔ 어두운 화면을 전환합니다(선택은 이 컴퓨터에 유지, 문서에는 저장 안 됨). UI만 바뀌고 **악보(종이)는 늘 흰색**이라 인쇄·PNG 출력은 그대로입니다. 다크에선 테마와 무관하게 시그니처 색이 **파란색**으로 바뀌어 가시성이 높고, 검은 선으로 그려진 시김새·장단 팔레트 기호도 흰 선으로 반전되어 잘 보입니다(악보 위 기호는 검정 유지).
- **글자는 드래그로 선택되지 않습니다** — 이 앱에서 마우스를 끄는 일은 대개 '정간 고르기·창 옮기기·기호 위치 조정'이라, 라벨이나 악보 글자가 함께 선택되면 방해가 됩니다. 선택이 되는 곳은 입력칸과 **읽고 옮길 만한 글**(안내문·도움말·둘러보기 본문)뿐입니다.

## 18. 도움말 · 둘러보기 · 처음처럼 다시 보기

- **도움말**(상단바 ? 버튼): 큰 모달 4탭 — **정간보란?**(정간보 기초) · **시작하기**(네 단계 안내) · **입력 방법**(율명 표기·붙임/분박·입력 문법표) · **단축키**. 맨 아래 **둘러보기 다시 시작** 버튼으로 투어를 언제든 다시 볼 수 있습니다.
- **환영 카드**: 진짜 첫 방문(저장된 작업·환영 카드를 본 기록이 전혀 없을 때)에만 뜹니다 — **둘러보기 시작 / 도움말 열기 / 바로 시작** 중 무엇을 골라도 끝나면 새 문서 마법사로 이어집니다.
- **둘러보기(투어) — 4장 · 16단계**: 화면을 어둡게 덮고 실제 UI를 하나씩 밝히며 설명합니다. 카드 맨 위의 **장 칩**(1 개요 · 2 입력 · 3 꾸미기 · 4 마무리)이 전체 목차를 늘 보여주고, **칩을 누르면 그 장 첫 단계로** 건너뜁니다. 칩 아래 얇은 **진행 바**가 전체 진행도, 단계 번호는 `2-1` 꼴(대번호-소번호). 끝까지 본 뒤 '완료'를 누르면 축하 카드가 나옵니다(건너뛰기·Esc는 축하 없이 종료).
  - **1장 개요**: 1-1 **정간보**(악보 읽는 법 — 앱 이야기 전에 정간보부터) → 1-2 기능바 → 1-3 악보 → 1-4 설정(사이드바)
  - **2장 입력** — 입력 그룹을 기능바 순서대로: 2-1 **정간 입력·율명**(율명 팔레트를 열어 두고, 한글 입력 문법 + 예시 그림) → 2-2~2-4 시김새(팔레트·숫자 단축키·**편집(위치·삭제)**) → 2-5 **곁줄** → 2-6 장단 → 2-7 **빠르기·각 이름(章)** → 2-8 **텍스트·제목**
  - **3장 꾸미기**: 3-1 **정간 서식(배경색·가로줄)** — 창을 연 채 배경색·정간·가로줄·초기화를 짚습니다(가로줄 모양 3종은 실제 렌더 캡처)
  - **4장 마무리**: 4-1 들어보기 → 4-2 새 문서·인쇄·파일 → 4-3 도움말
  - **1장 '정간보' 단계는 악보에서 정간·대강·각을 이름표 상자로 직접 짚습니다** — 무엇을 가리키는 말인지 모른 채 넘어가면 뒤가 다 헛돌기 때문입니다. 셋은 각기 다른 각에 있고 색도 달라 서로 겹쳐 보이지 않습니다.
  - 2장의 곁줄·장단 단계도 악보의 **그 줄 자체**를 함께 밝힙니다(곁줄이 아직 없으면 정간 오른쪽 '진입로'를 가리킵니다).
  - 화면에 없는 요소(예: 접힌 사이드바, 꺼진 장단 줄)는 그 강조·단계만 자동으로 건너뜁니다(번호는 고정).
  - 어두운 덮개는 SVG 마스크라 **강조 대상마다 진짜로 밝게 뚫립니다** — 메인 대상뿐 아니라 함께 가리키는 보조 버튼·이름표 상자도 밝아집니다.
  - **문구는 `js/tour-text.js`에서 직접 고칩니다**(코드 몰라도 됨) — 각 단계 title·body의 따옴표 안 글자만 바꾸면 됩니다. 파일 맨 위에 표기법(`\n` 줄바꿈, `**굵게**`, `!! ` 팁 상자, `## ` 소제목)과 글 꼴 규칙(`**항목 이름**: 내용`, 맺음은 "~할 수 있습니다")이 적혀 있습니다. 단계 추가·하이라이트 위치·예시 그림은 `js/app.js`의 TOUR_STEPS 소관.

- **처음처럼 다시 보기 — 주소 뒤에 `?first=1`**: 온보딩(환영 카드 → 둘러보기)을 첫 방문처럼 다시 봅니다. 강력 새로고침(⌘⇧R)은 HTTP 캐시만 비우고 `localStorage`는 그대로 두므로 아무리 눌러도 첫 방문이 되지 않아서 둔 기능입니다.
